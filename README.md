# ScholarSathi project files

The website uses the HTML/CSS/JavaScript pages in `frontend/`, served by its Express auth server. The separate Python service in `backend/api.py` supplies live eligibility matches from Neon; Express calls it server-to-server, so the browser never receives the internal API key. The active authenticated workspace pages live in `frontend/private-pages/`; keep same-named authenticated pages out of `frontend/public/` because Vercel serves public files from its CDN before Express authorization can protect them. The sibling `extension/` folder contains the unpacked Chrome extension; see `extension/README.md` for installation and local connection details.

For local development, run the Node app from `frontend/` with `npm install` and `npm run dev`. In another terminal, run the matching API from `backend/` with `py -3.11 -m uvicorn api:app --host 127.0.0.1 --port 8000`. Set the same `DATABASE_URL` and `INTERNAL_API_KEY` in both services; set the Node app's `FASTAPI_BASE_URL=http://127.0.0.1:8000`. For deployment, deploy the frontend and FastAPI service so each has a reachable URL, then set `FASTAPI_BASE_URL` on the frontend host. See `frontend/README.md` for remaining environment and deployment settings. Do not commit `.env`, `node_modules/`, `.vs/`, or student documents.
